# Personal Homepage

Source for [rookiie.github.io](https://rookiie.github.io), a lightweight Jekyll site hosted by GitHub Pages.

## Pages

- Home: biography, news, recent research, and experience
- Research: featured projects and project notes
- Contact: email and academic profiles

## Local preview

```bash
bundle install
./run_server.sh
```

Then open <http://127.0.0.1:4000>.

## Editing

- Homepage content: `_pages/about.md`
- Research index and notes: `research/`
- Contact page: `contact/index.md`
- Shared layouts: `_layouts/`
- Site styles: `assets/css/main.scss`
